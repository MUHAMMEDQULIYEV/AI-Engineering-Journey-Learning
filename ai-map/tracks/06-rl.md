# 06 · Reinforcement learning → RLHF / DPO (6 weeks)

🧪 draft, not walked yet

**Goal:** you can write Q-learning, a DQN and REINFORCE yourself, run PPO from a library, and explain how RLHF and DPO turn preferences into a better LLM.
**Done:** your own DQN solves CartPole and a DPO run on a small LLM shows a before/after table, both pushed · 🔒 explain the Q-learning update and the DPO idea in 5 sentences each, then write the Q-learning update loop in ≤20 lines, no notes.

**Prerequisites:** [03 deep learning](03-deep-learning.md) (PyTorch loop). For weeks 5–6: [04](04-llms.md) core, and ideally its Block 8 LoRA setup.

Day jobs: [../../roadmap/README.md](../../roadmap/README.md). LEARN = 👀 first, ≤30 min reading, 1 predict question. BUILD = without the course. SHIP = push. REVIEW = AI-off recall + blank-file rebuild.
GPU: weeks 1–4 run on CPU. Weeks 5–6 use the free Colab T4 (small model + LoRA).
📄 Paper every 2 weeks ([08](08-research.md)): *DQN* (Mnih et al., 2015), *PPO* (Schulman et al., 2017), *DPO* (Rafailov et al., 2023).
